## ✨ Что умеет

- **💬 Бот без кнопок и команд.** «кофе 350», «такси 1200 вчера», «сколько потратил на еду в этом месяце», «последнее было не 350, а 450», «удали такси» — агент сам вызывает нужные операции. Если не ясно, о какой трате речь, переспрашивает, а не угадывает.
- **🔒 Каждый видит только свои траты.** Изоляция обеспечивается кодом: агенту недоступны чужие данные, даже если модель попытается.
- **📊 Панель для главы семьи.** Итоги за период, разбивка по категориям и участникам, фильтры, добавление, правка и удаление с отменой. Тёмная и светлая темы, телефон.
- **👪 Семья по ссылке.** Глава создаёт в панели приглашение «Мама» — ссылку и QR. Мама открывает её, нажимает «Запустить» и сразу пишет траты: ни ID, ни правки конфига.
- **🧪 Проверяемое качество.** Тесты на настоящем Postgres с `-race`, набор из 48 фраз для оценки агента на настоящей модели, CI.

## 🚀 Быстрый старт

```bash
make up
```

Это `cp .env.example .env && docker compose up --build`: Postgres → разовые миграции → приложение.

- Панель: **http://localhost:8080** — сразу с демо-семьёй.
- Документация API: **http://localhost:8080/docs**.

Для бота нужны два значения в `.env`: `TELEGRAM_TOKEN` от [@BotFather](https://t.me/BotFather) и `LLM_API_KEY`. По умолчанию — Claude (`claude-opus-5-5`); примеры для OpenAI, OpenRouter, Gemini (есть бесплатный уровень) и Ollama — в [.env.example](.env.example). Без токена запускается только панель. Пошагово — в [гайде ниже](#-гайд-от-нуля-до-первой-траты).

## 📖 Гайд: от нуля до первой траты

Нужен только Docker. Все настройки — в одном файле `.env` в корне проекта: его создаёт первый `make up` из [.env.example](.env.example).

### 1. Что где взять и куда вписать

| Что | Где взять | Строка в `.env` |
|---|---|---|
| Токен бота | Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → придумать имя и адрес на `bot` (например `my_family_spend_bot`) → BotFather пришлёт токен вида `123456789:AAE…` | `TELEGRAM_TOKEN=` |
| Ключ LLM | Бесплатно — Gemini: [Google AI Studio](https://aistudio.google.com/apikey) → «Create API key». Или ключ Claude, OpenAI, OpenRouter | `LLM_API_KEY=` |
| Адрес и модель LLM | Для Gemini — две строки ниже; для других — готовые строки в `.env.example` | `LLM_BASE_URL=`, `LLM_MODEL=` |
| Кто в семье | Пока можно оставить пустым — см. шаг 4 | `FAMILY_MEMBERS=` |

Пример для бесплатного Gemini (вторая модель — запасная: бесплатные модели иногда перегружены, и тогда бот сам переходит к следующей):

```ini
TELEGRAM_TOKEN=123456789:AAE…
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
LLM_API_KEY=…ключ из AI Studio…
LLM_MODEL=gemini-3.6-flash,gemini-3.5-flash
```

Значения пишутся сразу после `=`, без кавычек и пробелов. Файл `.env` не попадает в git; токен и ключ никому не пересылайте — если засветились, перевыпустите (`/revoke` в BotFather, новый ключ в AI Studio).

### 2. Запуск

```bash
make up
```

Когда в логе появится строка `telegram bot started (long polling)` с адресом бота, всё готово. Панель — **http://localhost:8080**. После любой правки `.env` остановите (`Ctrl+C`) и снова выполните `make up`.

### 3. Первая трата

Откройте в Telegram `t.me/<адрес вашего бота>`, нажмите «Запустить» и напишите `кофе 350`. Бот ответит, что записал, а трата появится в панели (обновите страницу). Дальше — обычным текстом, примеры [ниже](#-как-говорить-с-ботом).

### 4. Закрыть семью от посторонних

Пока `FAMILY_MEMBERS` пустой, бот пускает любого, кто его найдёт. Для настоящей семьи:

1. Напишите боту сами (шаг 3) — вы появитесь в семье.
2. Откройте http://localhost:8080/api/users и найдите себя по имени из Telegram — рядом ваш `id`.
3. Впишите `FAMILY_MEMBERS=<ваш id>:Имя` (например `FAMILY_MEMBERS=123456789:Папа`) и перезапустите `make up`.

Теперь войти можно только по приглашению.

### 5. Пригласить семью

В панели: **«Семья»** (кнопка в шапке) → «Как подписать»: `Мама` → **«Создать ссылку»**. Дальше одно из трёх:

- **«Отправить в Telegram»** — выбрать чат с мамой;
- **«Копировать»** — и переслать ссылку где угодно;
- показать **QR** — мама наводит камеру телефона.

Мама открывает ссылку, нажимает «Запустить», и бот отвечает «Привет, Мама! Ты в семье». Ссылка одноразовая и живёт 7 дней. В том же окне можно поправить имя любого участника: кликните по нему, исправьте и нажмите Enter.

### 6. Панель на каждый день

- **Период** — кнопки сверху: сегодня, 7 дней, этот и прошлый месяц, всё время. Точные даты, участник, категория и поиск — в фильтрах.
- **Клик по полосе** категории или участника — показать только эти траты; повторный клик — снять фильтр.
- **«Добавить»** (или клавиша `N`) — трата вручную за любого участника. Карандаш в строке — изменить, корзина — удалить; удаление можно отменить кнопкой «Вернуть» в уведомлении.

### Если что-то не так

Подробности любой ошибки — в логе: `make logs`.

| Что видите | Почему и что делать |
|---|---|
| Бот отвечает «Не получилось обработать сообщение» | Не ответила LLM. В логе `llm status 503` — модели перегружены: добавьте в `LLM_MODEL` ещё одну запасную через запятую или замените их; `401`, `403` или `API key not valid` — неверный `LLM_API_KEY`; `404` — нет такой модели |
| Бот молчит | Неверный `TELEGRAM_TOKEN` — приложение не стартует, причина в логе. `error get updates … Conflict` — бот с этим токеном уже запущен где-то ещё |
| «Этот бот только для участников семьи» | Человека нет в `FAMILY_MEMBERS` и он не входил по приглашению — пришлите ему ссылку (шаг 5) |
| «Ссылка-приглашение недействительна» | Ссылку уже использовали или прошло 7 дней — создайте новую |
| «Бот не запущен» при создании приглашения | Не задан `TELEGRAM_TOKEN` — шаг 1 |
| Панель пишет `unknown host … add it to PANEL_HOSTS` | Панель открыта по доменному имени — впишите его в `PANEL_HOSTS` |

## 👪 Кто есть кто

| Роль | Где | Что видит и может |
|---|---|---|
| **Участник** | бот в Telegram | только свои траты: записать, посмотреть, изменить, удалить |
| **Глава семьи** | веб-панель | траты всех, правка любых, приглашения и имена участников |

Бот узнаёт человека по Telegram ID из самого сообщения — его не подделать текстом. По ТЗ у панели нет авторизации, поэтому глава — тот, у кого есть доступ к панели (по умолчанию только с этого компьютера). Приглашать может только он: в боте такой команды нет.

**Как добавить человека:** «Семья» → «Пригласить» → «Мама» → «Создать ссылку». Ссылку можно отправить через Telegram, скопировать или показать QR. Мама открывает её, нажимает «Запустить», бот получает одноразовый код (`/start <код>`) и здоровается: «Привет, Мама! Ты в семье». Ссылка работает один раз и 7 дней — пересланная дальше, она никого не пустит. Имя любого участника правится прямо в списке.

## 💬 Как говорить с ботом

| Сообщение | Что делает агент |
|---|---|
| `кофе 350` | `add_expense`: 350 ₽, еда, сегодня |
| `такси 1200 вчера` | дату считает от «сегодня» в `APP_TIMEZONE` |
| `метро 70 и кофе 200` | две траты отдельными вызовами |
| `кофэ 350`, `шаверма 250` | понимает опечатки и сленг; в комментарий пишет нормальное слово, чтобы трату потом нашёл поиск |
| `сколько потратил на еду в этом месяце` | `sum_expenses` — сумму считает SQL, не модель |
| `покажи траты за неделю` | `find_expenses` за 7 дней; длинный список заканчивается «и ещё N на X ₽» |
| `последнее было не 350, а 450` | находит последнюю добавленную и меняет сумму; если сумма не совпала — переспрашивает |
| `удали такси` | одна такая трата — удаляет; несколько — перечисляет и спрашивает какую |
| `удали все траты` | ничего не трогает без явного подтверждения |

## 🏗 Архитектура

Один Go-бинарник и Postgres. Подкоманды: `serve` (API, панель, бот) и `migrate`.

```mermaid
flowchart LR
    U(["Член семьи"]) -- "«кофе 350»" --> TG["Telegram"]
    TG -- "long polling" --> BOT["bot<br/>личка · дедуп · лимиты · очередь"]
    BOT --> AG["agent<br/>tool calling, 5 инструментов"]
    AG <--> LLM[("LLM<br/>OpenAI-совместимый API")]
    AG -- "db.ForUser(автор)" --> ST["expense.Store<br/>ограничение в каждом SQL"]
    H(["Глава семьи"]) --> WEB["Панель<br/>HTML · CSS · JS"]
    WEB -- "REST" --> API["api<br/>Host check · CSRF"]
    API -- "db.ForFamily" --> ST
    ST --> PG[("PostgreSQL")]
    BOT -- "история · блокировки" --> PG
```

| Пакет | Ответственность |
|---|---|
| [`internal/expense`](internal/expense) | модель, деньги, категории, валидация; SQL; хранилище, ограниченное семьёй или пользователем; участники |
| [`internal/agent`](internal/agent) | цикл tool calling, инструменты, системный промт, LLM-клиент |
| [`internal/bot`](internal/bot) | приём сообщений и состояние диалогов: история, защита от повторов, лимиты, блокировки |
| [`internal/api`](internal/api) | REST API, OpenAPI, middleware безопасности, раздача панели |
| [`web`](web) | панель: HTML + CSS + JS без сборки, встроена в бинарник |
| [`migrations`](migrations) | схема (goose), применяется отдельной командой |

Зависимости идут в одну сторону: `bot → agent → expense`, `api → expense`.

### Ключевые решения

- **Изоляция кодом, а не промтом.** Агент получает только хранилище `db.ForUser(...)`, созданное из `message.From.ID`. Чужой id от модели даёт «не найдено» — это проверяют тесты.
- **Tool calling вместо «фраза → JSON».** Для «удали такси» и «последнее было не 350» модели нужно видеть траты пользователя.
- **Деньги — копейки в `int64`**, в БД `NUMERIC(12,2)`. **`spent_at` — `DATE`.** **Суммы — в SQL.**
- **Ответ модели проверяется как ввод из API:** категория из списка (плюс `CHECK` в БД), сумма больше нуля, дата не в будущем. Ошибка уходит модели — та переспрашивает.
- **Сбой модели после изменения** не превращается в «не получилось»: бот перечисляет сделанное, чтобы пользователь не повторил сообщение и не задвоил трату.
- **Без лишних слоёв.** Нет service/repository-интерфейсов с одной реализацией; интерфейс один — LLM (настоящий клиент и поддельный в тестах).
- **Пагинация `limit/offset`.** У семьи тысячи трат, а не миллионы; индекс `(family_id, spent_at)` держит её дешёвой. Курсорная понадобится при постоянной ленте с вставками в начало.

### Готовность к масштабированию

Сделано сразу, потому что потом дорого менять: `family_id` в схеме; всё состояние в Postgres (история, дедуп по `update_id`, `pg_advisory_lock` на пользователя); миграции отдельной командой под блокировкой; очередь сообщений на пользователя, ограничение параллельности и лимит в час.

Включается по необходимости: webhook вместо polling (`bot.Process` не зависит от транспорта), очередь на Postgres, раздельный запуск API и обработчиков, авторизация панели через Telegram Mini App, разбор простых сообщений без LLM.

```bash
make eval   # агент против настоящей модели из .env
```

- **Тесты** на настоящем Postgres: изоляция пользователей, фильтры и суммы, защита от повторов, блокировки, API и защита панели, агент с поддельной LLM (включая попытки тронуть чужую трату и сбой после изменения), бот (группы, `/start`, посторонние, лимиты, пачка сообщений не блокирует остальных).
- **Eval агента:** 48 фраз в семи группах — запись, просмотр, изменение, удаление, безопасность, опечатки и сленг, прочее. Случай засчитывается по итоговому состоянию БД и аргументам вызовов, а не по формулировке ответа. «Сегодня» зафиксировано, поэтому даты проверяются точно. Механизм проверен на заглушке LLM; на настоящей модели набор ещё не прогонялся — `make eval`, отчёт появится в `docs/eval-results.md`.
- **CI** ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)): gofmt, vet, тесты с `-race`, golangci-lint, сборка образа.
- **Сканеры:** `govulncheck` — уязвимостей в зависимостях нет; `gosec` в линтере.

## 🤖 Как использовался ИИ

ТЗ рекомендует писать код с ИИ-ассистентом и оценивает, насколько качественно это сделано. Проект написан в паре с Claude Code: ассистент предлагал и писал код, решения и проверка оставались за человеком.

- **Шагами:** план → код → тесты на настоящем Postgres → чтение диффа → коммит. Каждый шаг закрывался зелёными `go test -race`; позже к ним добавились golangci-lint с gosec и CI.
- **Проверка, а не доверие.** Панель смотрели в браузере на телефоне и десктопе; спорные места в документации провайдеров проверяли живыми запросами; каждое требование сверено с ТЗ построчно.
- **Ошибки ассистента ловились и записаны:** `temperature: 0`, на который новые модели отвечают 400; интервал из `time.Duration.String()`, который не разбирает Postgres; потерянная подпись мыслей Gemini, из-за которой падала бы каждая трата; предложенная команда `/invite` в боте, хотя ТЗ просит «без кнопок и команд».
- **Безопасность отдельным проходом:** сканеры и перечитывание кода со сценариями атак нашли DNS rebinding, CSRF и дубли трат после сбоя модели — всё закрыто тестами.

Полный журнал решений и ошибок — [docs/ai-log.md](docs/ai-log.md).

## 🛡 Безопасность и приватность

**Бот:** изоляция кодом; только личные сообщения; при заданном `FAMILY_MEMBERS` пускает только их и вошедших по приглашению, посторонний получает отказ; в открытом режиме при старте пишется предупреждение. Код приглашения — 128 случайных бит, одноразовый (повторное использование отсекает сам `UPDATE … WHERE used_at IS NULL`), живёт 7 дней.

**Панель** без авторизации по ТЗ, поэтому защищено то, что можно защитить без неё:
- по умолчанию слушает только `127.0.0.1`;
- **DNS rebinding:** доменное имя в `Host`, которого нет в `PANEL_HOSTS`, получает 421 — иначе страница злоумышленника с доменом на 127.0.0.1 прочитала бы все траты;
- **CSRF:** стандартный `http.CrossOriginProtection` отклоняет изменяющие запросы с чужих сайтов;
- запрет встраивания во фрейм, `nosniff`; скрипты Swagger UI с CDN закреплены SRI-хэшами.

Открывать панель в интернет без прокси с авторизацией или VPN не стоит.

**Данные:** провайдеру LLM уходят текст сообщения, история за 6 часов и траты автора, которые вернули инструменты — траты других членов семьи не уходят. Переписка удаляется через 7 дней. В логах уровня `info` нет текстов сообщений и сумм; токен бота библиотека маскирует.

## 📝 Допущения и нюансы

- Один запуск сервиса — одна семья; рубли; общий часовой пояс. Глава семьи в боте видит только свои траты, все — в панели.
- Чтобы закрыть семью для посторонних, впишите в `FAMILY_MEMBERS` хотя бы себя — дальше войти можно только по приглашению. Удаления участника пока нет: трата всегда принадлежит кому-то, и решать, что делать с его историей, — отдельная задача.
- «Последняя трата» — последняя добавленная. «За неделю» — 7 дней, «на этой неделе» — с понедельника, «в этом месяце» — с 1-го числа.
- Сообщения одного пользователя обрабатываются по очереди; сообщения, которые обрабатывались при остановке сервиса, остаются без ответа.
- Редактирование сообщения в Telegram не меняет трату. Контекст диалога — 10 сообщений за 6 часов.
- «Сегодня» в форме панели — из пояса браузера, проверка — в `APP_TIMEZONE`; около полуночи при разных поясах дата может быть отклонена.
- LLM подключается через OpenAI-совместимый API ради смены провайдера одной настройкой. У Claude этот режим [не рекомендован для продакшена](https://platform.claude.com/docs/en/api/openai-sdk) — для продакшена стоит добавить нативный клиент Anthropic.
- Ollama в compose не добавлена: небольшие модели заметно хуже вызывают инструменты, а веса на гигабайты замедлили бы первый запуск. Подключается через `LLM_BASE_URL`.
